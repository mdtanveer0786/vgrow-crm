# UI Context: VGROW CRM

## 1. Visual Language
- **Vibe:** Modern, premium, clean, SaaS dashboard.
- **Colors:** Vibrant accents (blue for primary actions, green for positive scores, orange/red for needs attention). Backgrounds should be light and clean (or dark mode compatible), with glassmorphism touches.
- **Typography:** Clean sans-serif fonts (e.g., Inter, Roboto).
- **Layout:** Fixed left sidebar, top header bar, and a main scrolling content area.

## 2. Key Components
- **Sidebar:** Contains logo, collapsible sections (Dashboard, Activities, Pipeline, etc.), and user profile badge at the bottom.
- **Topbar:** Search bar (`Ctrl+K`), AI Assistant ("Meet Karan"), Tasks, Notifications, Settings, and Language switcher.
- **Cards/Widgets:**
  - `Profile Health Score`: Circular progress gauge showing score (e.g., 17/100).
  - `CRM Hygiene Score`: Circular progress gauge.
  - `Today's Activity`: Actionable list with micro-animations on hover.
  - `Getting Started`: Step tracker (e.g., "5 of 6").

## 3. Interaction Design
- Add micro-animations (subtle scaling, shadow changes) on button and card hovers.
- Ensure smooth transitions when switching tabs or expanding sidebar items.
